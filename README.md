🧑‍💻 Sistema de Cadastro de Usuários (Fullstack)

📌 Sobre o projeto

Este projeto é uma aplicação fullstack de cadastro de usuários, desenvolvida com React no frontend e Node.js no backend, utilizando banco de dados MongoDB com Prisma.

A aplicação permite cadastrar usuários e visualizar os dados inseridos em tempo real.

🧠 Arquitetura do projeto

Frontend (React + Vite)
        ↓
Requisições HTTP (API REST)
        ↓
Backend (Node.js)
        ↓
Prisma ORM
        ↓
MongoDB


🚀 Funcionalidades


📝 Cadastro de usuários
📥 Entrada de nome, e-mail e mensagem
📊 Exibição dos dados cadastrados
🗑️ Remoção de usuários
🔄 Atualização em tempo real (UI)
📡 Integração com API
